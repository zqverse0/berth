# berth-term-engine

> **Private API.** Internal Berth terminal implementation; semver is not
> guaranteed inside `0.x`.

Core in-memory session, pane, layout, format, hook, and buffer model used by
the terminal daemon. Use `berth-term-sdk` for the stable client-facing API.
